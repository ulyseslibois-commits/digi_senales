Funcionalidad principal

- Digitalizacion de señales

Intalación y ejecución

Instalar librerias  en vs code
Comandos en consola de vs code:
-    pip install streamlit
(libreria para aplicacion web interactiva)

Comando en consola de vs code:
-    pip install numpy
(liberia para calculos númericos y arrays)

Comando en consola de vs code
-    pip install matplotlib
(Libreria para crear graficas estilo matlab)

Forma de ejecucion:
en power shell de windows y parados dentro del directorio donde se encuentra nuestro proyecto:
-    py -m streamlit run "digitalizacion de imagenes.py"
